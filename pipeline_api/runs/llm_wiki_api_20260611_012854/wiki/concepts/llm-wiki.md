# LLM Wiki

## Definition
LLM을 활용해 지속적으로 업데이트되는 개인 지식 베이스로, 위키 형식으로 지식을 구조화합니다. [B0001, B0002, B0006]

## Key Points
- LLM Wiki는 개인 지식 베이스를 구축하기 위한 패턴으로, 위키 형식으로 정보를 구조화합니다. [B0002]
- 새로운 소스가 추가될 때 LLM은 해당 내용을 읽고 핵심 정보를 추출하여 기존 위키에 통합합니다. [B0006]
- 지식 베이스는 지속적으로 업데이트되며, 새로운 데이터가 기존 주장과 모순되는 경우 이를 명시합니다. [B0006]

## Evidence
- LLM Wiki는 단순한 문서 검색을 넘어, 지속적으로 유지되는 구조화된 위키를 구축합니다. [B0006]
- 이 방식은 지식을 한 번 컴파일한 후 지속적으로 최신 상태로 유지하며, 매 쿼리 시 재파생하지 않습니다. [B0006]
