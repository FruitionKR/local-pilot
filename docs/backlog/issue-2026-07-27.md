# 2026-07-27 AI/Pipeline 해결 기록

## 재편입 후 Concept 본문 의미 정합성 복구

### 해결 내용

- `POST /wiki/maintenance/lint`가 재편입으로 영향받은 Concept Page를 찾고,
  Page·원문 문서별 최신 active contribution JSON만 선택해 본문을 다시 조립한다.
- 수정·삭제 전 contribution은 제외하고 다른 활성 문서의 최신 contribution은
  유지해 Definition, Evidence, Related Concepts를 결정적으로 재생성한다.
- `dry_run=true`에서는 `semantic_reconciliation_candidates`만 반환하고,
  `dry_run=false`에서는 Concept Markdown과 embedding unit을 lint transaction
  안에서 함께 갱신한다.
- orphan relation 판정에도 같은 최신 contribution 선택 규칙을 적용해 이전
  재편입 결과만 지지하던 relation을 제거할 수 있게 했다.
- 변경된 Page는 operation별 Markdown과 `content_action=rebuild` JSON artifact로
  저장되며, 재조립에 쓴 원문 문서·ingest operation ID도 함께 추적할 수 있다.

### 검증

- 수정 전 주장이 제거되고 최신 주장만 남는지 확인했다.
- 다른 문서가 지지하는 주장과 relation이 유지되는지 확인했다.
- dry-run이 Wiki Page와 embedding을 수정하지 않는지 확인했다.
- llmPipeline 전체 테스트 `803 passed, 61 subtests passed`로 검증했다.
