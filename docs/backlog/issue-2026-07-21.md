# 2026-07-21 해결 이슈 기록

## Backend — 빈 문서 생성 API 부재

### 기존 문제

- 문서 생성 API가 비어 있지 않은 multipart 파일만 받아, 사이드바에서 새 Markdown 문서를 만드는 기능을 연결하지 못했다.
- `documents.content_hash`가 필수라 내용 없는 placeholder row를 만드는 방식도 사용할 수 없었다.

### 해결

- 프론트엔드가 고유 식별 주석과 `# 새 문서` 제목을 가진 `새 문서.md`를 생성해 기존 `POST /api/workspaces/{workspace_id}/documents`로 업로드한다.
- 별도 빈 문서 endpoint나 nullable schema 변경 없이 새 노트 생성 요구사항을 충족했다.
- `npm run build`로 프런트엔드 타입과 production build를 검증했다.

### 남은 작업

- WYSIWYG 편집 결과를 저장할 본문 update API는 여전히 필요하다. `docs/issue/backend/2026-07-21.md`의 `2. 노트 본문 저장 API 부재`로 이관했다.
