# 2026-07-21 Frontend 이슈

`docs/issue/frontend/2026-07-15.md`와 다른 역할 문서에서 아직 해결되지 않은 Frontend 작업을 현재 날짜 기준으로 이관했다.

## 1. Query 진행상황 SSE 전환

- `queryWiki()`가 동기 POST만 호출하고 정적 진행 단계를 표시한다.
- Backend의 비동기 run 생성과 SSE endpoint를 사용해 단계별 진행 표시로 전환한다.
- 상세: `docs/backlog/issue-2026-06-20.md` 이슈 1, `docs/backlog/issue-2026-06-17.md`의 Frontend 후속 작업.

## 2. 문서 processing_state, processing_stage 표시

- Backend 상태 모델은 구현됐지만 Frontend는 `processing_state`, `processing_stage`를 소비하지 않는다.
- 문서 목록·업로드 UI에서 상태를 polling하고 stalled/failed 및 채팅 Wiki run 단계를 표시한다.
- 상세: `docs/backlog/issue-2026-06-26.md`의 Frontend 구현 범위, `docs/backlog/issue-2026-07-09.md`의 Frontend 후속.

## 3. Wiki page 이름 변경 연동

- Wiki graph/page 조회는 workspace 범위 경로로 전환됐지만 Wiki page rename 호출은 아직 없다.
- Backend의 workspace 범위 Wiki rename API를 Frontend에 연결한다.
- 기존 경로 전환 완료 기록은 `docs/changelog/frontend.md`의 `2026-07-18`을 참조한다.

## 4. wiki maintenance UI

- maintenance panel/proposal/summary UI와 lint client 타입·재동기화가 미구현 상태다.
- llmPipeline endpoint는 `docs/spec/llmpipeline-backend-output-contract.md`의 `5. Lint`를 따른다.
- Backend proxy는 `docs/issue/backend/2026-07-21.md`의 `5. wiki maintenance lint proxy`를 따른다.
- 상세: `docs/backlog/issue-2026-07-02.md` F1~F7.

## 5. query evidence source_refs 소비

- Frontend가 `source_refs`를 소비하지 않으며 block 기반 원문 렌더링 전환이 남아 있다.
- Backend 선행 작업은 `docs/issue/backend/2026-07-21.md`의 `6. query evidence source_refs 노출`을 따른다.
- 상세: `docs/backlog/issue-2026-07-02.md`의 `Query evidence source_refs 구조화 — 후속작업`.

## 6. 이메일 인증 API 연동

- Backend 이메일 인증 API가 구현되면 개발용 임시 인증번호 `9700`과 인증 전 회원가입 호출을 제거한다.
- 회원가입·비밀번호 재설정 화면을 실제 인증번호 발급·검증·token 계약에 연결한다.
- Backend 선행 작업은 `docs/issue/backend/2026-07-21.md`의 `1. 이메일 인증 기반 회원가입 계약`을 따른다.
