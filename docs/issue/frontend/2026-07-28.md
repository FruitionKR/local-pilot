# 2026-07-28 Frontend 이슈

## 개발 도구 의존성 보안 경고와 ESLint CLI 전환

### 현재 상태

- production 의존성은 `postcss 8.5.24` override 적용 후 `npm audit --omit=dev`가 0건이다.
- 전체 `npm audit`에는 ESLint 8 도구 체인의 `glob`, `minimatch`, `brace-expansion` 경로에서
  high 경고 13건이 남는다.
- `npm audit fix --force`는 ESLint 10 등 breaking 변경을 제안하므로 현재 Next.js 15 설정에
  자동 적용하지 않았다.
- `next lint`는 Next.js 16에서 제거될 예정이라는 deprecation 경고를 출력한다.

### 후속 작업

- Next.js와 `eslint-config-next`의 지원 조합을 확인해 ESLint CLI 설정으로 전환한다.
- ESLint 9 이상 전환 후 dev dependency audit를 다시 실행하고, 잔여 경고가 없도록 lockfile을
  갱신한다.
- `npm run lint`, `npm run test:markdown`, `npm run test:user-preferences`, `npm run build`를
  회귀 검증한다.

### 관련 코드와 확인 위치

- `frontend/package.json` — `lint`, `eslint`, `eslint-config-next`, `overrides`
- `frontend/package-lock.json` — dev dependency 해석 결과
- Next.js 실행 경고 — `npm run lint`
