# 2026-07-25 Frontend 이슈

## 문서·workspace 휴지통 연동

### 필요한 작업

- 문서 삭제 요청에 `Idempotency-Key`와 JSON `base_version`을 전달한다.
- `GET /api/workspaces/{workspace_id}/documents/trash`에서 삭제 문서를 표시한다.
- 문서 복구 시 `POST /api/workspaces/{workspace_id}/documents/{document_id}/restore`에 `Idempotency-Key`와 `base_version`을 전달한다.
- 복구 응답의 `current_version`, `sort_order`를 반영하고 역할별 최상위 마지막에 표시한다.
- workspace 삭제·복구에는 `base_version`을 사용하지 않고 `Idempotency-Key`만 전달한다.
- `GET /api/workspaces/trash`에서 소유자가 삭제한 workspace를 표시한다.
- 삭제 workspace의 기존 문서·채팅·Wiki가 복구 후 다시 나타나도록 로컬 cache를 무효화한다.
