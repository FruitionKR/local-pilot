# 2026-07-22 AI/Pipeline 이슈

## Agent target model 반복 평가

Agent 전체 편집 line 계산과 예상하지 못한 500 응답 보호는 해결했다. 구현 기록은 `docs/backlog/issue-ai-2026-07-22.md`의 `Agent 전체 편집 line 계산과 500 응답 보호`를 참조한다.

다음 target model 검증은 아직 남아 있다.

- 요약, 번역, cleanup, 표, checklist, 회의록 fixture를 각 3회 실행한다.
- `chat_answer`, `markdown_edit`, `markdown_create`, `clarify`, `reject` action 정확도를 확인한다.
- Markdown 출력 계약 통과율과 p95 latency를 기록한다.
- 대화 기반 생성이 실제 요약과 reference context를 사용하는지 확인한다.

Spring public endpoint를 통한 권한·version·DTO·오류 mapping E2E는 `docs/issue/backend/2026-07-21.md`의 `4. Markdown Agent turn public endpoint 부재`에서 관리한다.

### 완료 조건

- 대표 fixture 반복 결과와 action 정확도, 계약 통과율, p95 latency가 문서화된다.
- 대화 context를 사용하는 생성 fixture가 통과한다.

### 확인 위치

- HTTP 평가 도구: `llmPipeline/markdown_agent_http_lab.py`
- Markdown 편집 평가 도구: `llmPipeline/markdown_edit_gfm_lab.py`
- HTTP endpoint: `llmPipeline/app/modules/agent/interfaces/http/routes.py`의 `POST /agent/turn`
- 전체 계약: `docs/spec/agent-markdown-contract.md`
