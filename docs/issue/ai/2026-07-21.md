`docs/issue/ai/2026-07-15.md`에서 아직 해결되지 않은 항목을 현재 날짜 기준으로 이관했다.

## 1. pipeline run 동시 실행 방지

- 여러 문서 동시 업로드 시 DB 큐(PR 55)는 도입됐으나 worker가 POST 직후 큐 항목을 삭제해 pipeline run 동시 실행이 여전히 가능하다.
- 선택지: llmPipeline 내부 lock(`asyncio.Lock`/Semaphore) 채택 또는 backend `PipelineRunRequest`에 `wait=true` 필드 추가(`api.py:89`에 `wait` 파라미터는 이미 존재).
- 상세: `docs/backlog/issue-2026-06-29.md` 이슈 1, `docs/backlog/issue-2026-06-26.md` 동시 업로드 처리 순서.

## 2. pipeline run heartbeat

- `pipeline_runs`에 `updated_at`이 없고 `touch_pipeline_run`도 구현되지 않았다. backend 측 수신부(`applyPipelineEvent`, `markProcessingHeartbeat`)는 구현되어 있어 송신부 구현이 남아 있다.
- 상세: `docs/backlog/issue-2026-06-26.md` llmPipeline heartbeat, `docs/backlog/issue-2026-06-29.md` 참조 절.
