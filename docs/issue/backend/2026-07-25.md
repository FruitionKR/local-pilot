# 2026-07-25 Backend 이슈

## 계층 트리 삭제·복구

### 현재 범위

- Core `TASK-008`은 문서 한 건의 소프트 삭제·휴지통·복구를 제공한다.
- 개별 복구 문서는 역할별 최상위 마지막 위치에 배치한다.
- workspace 소프트 삭제는 하위 문서·채팅·Wiki·멤버십을 변경하지 않고 workspace 접근 경계만 닫는다.

### 후속 작업

- 부모 페이지 삭제 시 전체 하위 페이지를 같은 `delete_operation_id`로 삭제한다.
- 전체 트리 복구는 기존 부모와 순서를 복원한다.
- 하위 트리 개별 복구는 최상위 마지막 위치에 배치한다.
- 원본 폴더 트리 삭제·복구를 구현한다.
- 영구 삭제 보존 기간과 실행 주체를 결정한다.
