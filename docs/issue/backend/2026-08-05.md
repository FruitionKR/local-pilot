### 배경

- 상세 계약은 `docs/spec/sdd/markdown-document-assets.md`의 **REQ-001~REQ-009**와
  **6. 설계 / Multipart 계약**을 따른다.
- 구현 순서는 `docs/spec/sdd/tasks/markdown-document-assets-tasks.md`의 `TASK-001`~`TASK-009`를

### 변경 이유와 영향

- 이미지 bytes를 문서 저장과 연결하기 전에 DB 무결성 경계를 먼저 고정하기 위한 기반 작업이다.
- migration은 병렬 AI 작업의 `V15__add_ai_operation_logs.sql`과 충돌하지 않도록 `V16`을 사용한다.
- 기존 document API와 제품 동작은 아직 변경하지 않는다.
